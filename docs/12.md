# 第12章 タブーサーチと反復局所探索

> **到達目標（水色帯 1200〜1599）**: タブーリストで巡回を避け、反復局所探索（ILS）の骨格で TSP 的な解を改善できる。

---

## 12.1 タブーリストと多様性の確保

**霊夢**: 山登りや SA は、同じ手を何度も試しちゃうの？

**魔理沙**: **同じ局所解の周りをぐるぐる** 回ることがある。タブーサーチは **最近使った手（移動）を一時禁止** して、別の谷を探す。

| 用語 | 意味 |
|------|------|
| **タブー** | 禁止リストに載った移動 |
| **テニュア（tenure）** | 何ステップ禁止するか |
| **aspiration** | タブーでも「過去最良を更新」なら許可 |

**霊夢**: aspiration って、第12章のコードにある？

**魔理沙**: ある。`tabu_tsp.py` では **タブーでも `new_len < best_len` なら採用** する。

```python
# python/ch12/tabu_tsp.py
is_tabu = move in tabu_set
new_len = cur_len - before + after
if is_tabu and new_len >= best_len:
    continue  # タブーかつ最良更新にならない → スキップ
```

```go
// go/ch12/tabu_tsp.go — 同じ判定
if tabuSet[move] && newLen >= bestLen {
    continue
}
```

**霊夢**: タブーリストは deque で古いのから捨ててるのね。

**魔理沙**: `maxlen=tabu_tenure` の **FIFO** が定番。セット `tabu_set` で O(1) 判定、満杯時に `popleft` で古い手を解放する。

```python
tabu: Deque[Tuple[int, int]] = deque(maxlen=tabu_tenure)
if len(tabu) == tabu.maxlen:
    old = tabu.popleft()
    tabu_set.discard(old)
tabu.append(move)
tabu_set.add(move)
```

## 12.2 反復局所探索（ILS）の構成

**霊夢**: ILS って、山登りを何度もやり直す感じ？

**魔理沙**: **Iterated Local Search** は次の3点セットだ。

```
  初期解
    ↓
┌───────────────────┐
│ 局所探索（2-opt等）│←──┐
└─────────┬─────────┘   │
          ↓               │
      局所最適            │
          ↓               │
┌───────────────────┐   │
│  扰动（キック）    │───┘
└───────────────────┘
```

| 段 | 本リポジトリ |
|----|-------------|
| 初期解 | ランダムシャッフル（seed=42） |
| 局所探索 | タブー付き 2-opt 風 `reverse` |
| 扰动 | （演習で追加）ランダムスワップ |

**霊夢**: 今の `tabu_tsp` は ILS までやってない？

**魔理沙**: その通り。**タブー付き局所探索 1 本** だ。ILS にするには `max_iter` 後に **キック** して `cur` を乱し、外側ループで繰り返す（演習2）。

## 12.3 扰动（Perturbation）の設計

**霊夢**: 扰动って、解をわざと壊すの？

**魔理沙**: **局所最適から離れる** ための操作だ。強すぎると品質が落ち、弱すぎると抜け出せない。

| 扰动 | 向き | 注意 |
|------|------|------|
| ランダム 2-opt | TSP 向き | 短い逆転 |
| セグメント再配置 | VRP 向き | 容量制約を壊さない |
| 複数都市スワップ | 強い | あとで長めに局所探索 |

**霊夢**: 第6章の 2-opt と何が違うの？

**魔理沙**: 近傍の形は同じ。**タブーで「直前に戻す手」** を避ける点と、**aspiration で最良更新** を優先する点が違う。差分更新で `new_len = cur_len - before + after` としているのも同じ思想だ。

```python
def apply_reverse(tour: List[int], i: int, k: int) -> None:
    tour[i + 1 : k + 1] = reversed(tour[i + 1 : k + 1])
```

```go
func reverseSegment(tour []int, lo, hi int) {
    for lo < hi {
        tour[lo], tour[hi] = tour[hi], tour[lo]
        lo++
        hi--
    }
}
```

### パラメータ早見表

| パラメータ | 本リポジトリ | 上げると | 下げると |
|-----------|-------------|---------|---------|
| `tabu_tenure` | 12 | 同じ手の再訪が減る | 探索が硬くなる |
| `max_iter` | 800 | 改善余地↑・時間↑ | 早く止まる |
| seed | 42 | 再現性あり | 変えると初期経路が変わる |

**霊夢**: `max_iter` で打ち切るのは、改善手が見つからなかったとき？

**魔理沙**: `best_move is None` のときだ。全近傍が **悪化またはタブー拒否** なら停滞。ILS ではここで **扰动** を入れる。

## 12.4 ハンズオン: 経路問題にタブーサーチを適用する

**霊夢**: データは第6章と同じ形式？

**魔理沙**: 先頭が `n`、続けて `n` 点の座標。`data/ch12/sample.txt` は 8 都市だ。

```bash
python python/ch12/tabu_tsp.py < data/ch12/sample.txt
go run go/ch12/tabu_tsp.go < data/ch12/sample.txt
```

検証済み出力の例:

```text
n=8 before=48.49 after=28.98 tabu_tenure=12
```

**霊夢**: 48 から 29 まで下がってる。タブーなし山登りと比べたいの。

**魔理沙**: `tabu_set` 判定を常に `False` にするブランチを切り、同じ seed=42 で `before` / `after` を表にする。

### ハンズオンの進め方

1. **読む** — `tabu_search` の二重ループ `(i, k)` が 2-opt 近傍
2. **写す** — 上記コマンドで `tour:` 行を確認
3. **改変** — `tabu_tenure=12` を `6` / `24` に振る
4. **コンテスト形式** — `max_iter=800` を残り時間で打ち切る（第10章タイマーと合成）

### コアループ（抜粋）

```python
for _ in range(max_iter):
    best_move = None
    for i in range(n):
        for k in range(i + 2, limit):
            # before / after で差分評価
            ...
    if best_move is None:
        break
    apply_reverse(cur, i, k)
    if cur_len < best_len:
        best = cur[:]
```

```go
tour, after := tabuSearch(pts, tour, 12, 800)
fmt.Printf("n=%d before=%.2f after=%.2f tabu_tenure=12\n", len(pts), before, after)
```

### SA・山登りとの位置づけ

| 手法 | 悪化の受理 | 記憶 | 向く場面 |
|------|-----------|------|---------|
| 山登り | しない | なし | 速い仕上げ |
| SA | 確率的 | なし（温度のみ） | 広い谷 |
| タブー | 改善のみ（悪化はしない） | 最近の手 | 巡回・置換 |

**霊夢**: 第10章パイプラインにタブーを挟むなら？

**魔理沙**: `greedy → tabu → SA` のように **タブーで整数っぽく詰めてから SA** もあり得る。時間の `%` を stderr に出せ（第10章）。

```python
# 初期化（main より）
rng = random.Random(42)
tour = list(range(len(pts)))
rng.shuffle(tour)
before = tour_length(pts, tour)
tour, after = tabu_search(pts, tour, tabu_tenure=12, max_iter=800)
```

## 章末まとめ

**霊夢**: タブーは「同じ手のしつこさ」を防いで、aspiration で最良更新は逃がさないのね。

**魔理沙**: ILS はその上に **扰动で再起動** を載せる。まとめだ。

> **第12章まとめ**
>
> - **タブーリスト**で最近の移動を禁止し、探索の多様性を確保
> - **aspiration**: タブーでも過去最良を更新する手は許可
> - **ILS** = 局所探索 + 扰动 +（外側ループ）
> - 実装: `python/ch12/tabu_tsp.py` / `go/ch12/tabu_tsp.go` / `data/ch12/sample.txt`
> - 検証例: `before=48.49` → `after=28.98`（`tabu_tenure=12`）
> - 次章: Union-Find / Fenwick で合法操作生成を高速化（第13章）

**霊夢**: 第6章の 2-opt にタブーと aspiration が載った感じね。

**魔理沙**: 水色帯では **メタ手法の組み合わせ** が本題だ。次はデータ構造で **同じ近傍を何倍も速く** 試せるようにするんだぜ。
