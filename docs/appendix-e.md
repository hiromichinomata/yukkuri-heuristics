---

## コンテスト・評価

| 用語 | 説明 |
|------|------|
| AHC | AtCoder Heuristic Contest。ヒューリスティック部門の主力コンテスト |
| AC | Accepted。アルゴ部門では正解。ヒューリスティックでは「合法解」に近い |
| WA | Wrong Answer。出力形式違反・非法解 |
| TLE | Time Limit Exceeded。制限時間超過 |
| スコア | 高いほど良いことが多い。問題ごとに計算式が異なる |
| スコア関数 | 出力から点数を計算する関数。ローカル実装推奨 |
| Rated | レーティングが更新される参加 |
| 提出間隔 | AHC では同一問題へ **5分** 空ける |
| パフォーマンス | 1回のコンテスト成績から換算される実力推定値 |
| 単調非減少 | Heuristic レートは **下がらない**（第1章） |

---

## 解法の型

| 用語 | 説明 |
|------|------|
| ヒューリスティック | 最適保証なしで良い解を探す手法の総称 |
| 貪欲法 | 毎回ベストな局所選択。第5章 |
| 山登り法 | 改善する近傍のみ受理。第6章 |
| 2-opt | 経路の2辺を入れ替える近傍 |
| 焼きなまし法 (SA) | 確率的に悪化も受理。第8章 |
| ビームサーチ | 幅を制限した探索。第9章 |
| タブーサーチ | 最近の手を禁止して多様性を確保。第12章 |
| ILS | 反復局所探索。扰动+再最適化 |
| LNS | 大近傍探索。破壊と再構築。第24章 |
| MCTS | モンテカルロ木探索。UCB1 等。第19章 |
| GA | 遺伝的アルゴリズム。第16章 |
| 多腕バンディット | 探索と利用のトレードオフ。第25章 |
| multi-start | 複数初期解・シードで繰り返し最良を採用 |

## 実装・モデリング

| 用語 | 説明 |
|------|------|
| State | 解の現在形。第3章 |
| Move | 解を少し変える操作。近傍生成 |
| 近傍 (Neighborhood) | Move の集合 |
| 合法解 | 制約を満たす解 |
| 初期解 | 探索の出発点。ランダム・貪欲など |
| 差分更新 | スコアの全再計算を避け差分だけ求める。第13章 |
| 粗視化 | 細かい問題を粗い格子に落とす。第7章 |
| パイプライン | 貪欲→山登り→SA など段階的改善。第10章 |
| ビジュアライザ (vis) | 解を可視化するツール |
| ローカルテスター | gen / score / vis 等の手元評価環境 |
| TL | Time Limit。実行時間制限 |

## データ構造

| 用語 | 説明 |
|------|------|
| Union-Find | 素集合データ構造。連結判定。第13章 |
| Fenwick Tree | 累積和の差分更新。BIT とも |
| セグメント木 | 区間クエリ・更新 |
| ヒープ | 優先度付きキュー。`heapq` / `container/heap` |
| ダイクストラ法 | 非負重み最短路。第11章 |

## インタラクティブ

| 用語 | 説明 |
|------|------|
| インタラクティブ | ジャッジと対話しながら解く形式 |
| クエリ | ジャッジへの質問。真の情報が返る |
| オンライン | 入力が順次与えられる設定 |
| UCB1 | バンディットの選択則。第25章 |
| Thompson Sampling | ベイズ的なバンディット戦略 |

## コンテスト運用

| 用語 | 説明 |
|------|------|
| No Submit | 一度も提出しないこと。レート対象外になりがち |
| 最良解保持 | TLE 直前でも今までの best を出力 |
| シード | 乱数の初期値。再現性に影響 |
| PyPy3 | Python 高速実装。本番言語として選択可 |
| 短期コンテスト | 数時間完結 |
| 長期コンテスト | 約2週間。日次改善 |
