# 付録A 台本テンプレート

**霊夢**: 自分で章を書くとき、どんな型にすればいいの？

**魔理沙**: この付録をコピペの土台にすればいい。本書は **霊夢＝読者代理**、**魔理沙＝解説** だぜ。

---

## A.1 掛け合い解説の基本フォーマット

### 1節の骨格

```markdown
## N.M 節タイトル

**霊夢**: （素朴な疑問・「〜って何？」）

**魔理沙**: （一行定義 + なぜ重要か）

**霊夢**: （確認・よくある勘違い）

**魔理沙**: （表 or 箇条書き + コード）

```python
# python/chNN/example.py
...
```

```go
// go/chNN/example.go
...
```

**霊夢**: （理解を言い直す）

**魔理沙**: （次節への橋渡し or 注意点）

> **注**: 補足・本番との差異
```

### 会話の長さの目安

| 部分 | 行数目安 | 役割 |
|------|---------|------|
| 霊夢の質問 | 1〜3行 | 読者のつまずきを先回り |
| 魔理沙の解説 | 3〜8行 | 正確な説明 |
| コード | 必須 | 動く例を優先 |
| 章末まとめ | 3〜7 bullet | 復習用 |

### 避けること

- 霊夢だけ長独白（読者代理が解説し始める）
- コードなしの抽象論だけ（特に技法の章）
- 「ゆっくり＝学習速度が遅い」という誤用

## A.2 霊夢の質問パターン集

| パターン | 例 | 使うタイミング |
|---------|-----|---------------|
| 定義確認 | 「〇〇って何なの？」 | 新用語の導入 |
| 比較 | 「△△との違いは？」 | アルゴ部門との対比 |
| 不安 | 「難しそうなのだけど……」 | モチベーション |
| 突っ込み | 「じゃあ全部焼けばいいの？」 | 落とし穴の前 |
| 手順 | 「最初に何すればいいの？」 | ハンズオン前 |
| 言い直し | 「つまり□□なのね」 | 節の終わり |

### コピペ用フレーズ

```text
霊夢:
- 「魔理沙、〇〇って何なの？」
- 「アルゴだと△△だったけど、ヒューリスティックは違うの？」
- 「それ、本番でも使えるの？」
- 「ローカルで試すにはどうすればいいの？」
- 「パラメータ、感覚でいいの？」
- 「時間切れになったらどうするの？」
```

## A.3 魔理沙の解説パターン集

**推奨順序**: **定義 → 直感 → 具体例 → コード → 注意**

### 定義（1〜2文）

```markdown
**魔理沙**: **貪欲法**は、毎回いま一番良さそうな選択を繰り返す方法だ。
```

### 直感（比喩・表）

```markdown
**魔理沙**: 山登りは「近くの坂だけ見て上がる」。谷に落ちたら SA で飛び出す、だな。
```

| 技法 | 直感の一言 |
|------|-----------|
| 貪欲 | その場その場でベスト |
| 山登り | 近傍の中で改善だけ |
| 焼きなまし | たまに悪手で谷を越える |
| ビームサーチ |  promising な枝だけ残す |
| LNS | 大きく壊して作り直す |

### 具体例（問題に結びつける）

```markdown
**魔理沙**: Intro HC 問題A なら、「d 日目に満足度が最大になるタイプ」を貪欲に選ぶ、が典型だ。
```

### コード（Python + Go）

```markdown
**魔理沙**: リポジトリの `python/ch05/greedy_delivery.py` を見ろ。同じ考えが Go にもある。
```

### 注意（落とし穴）

```markdown
**魔理沙**: 貪欲は **最適保証がない**。だからスコア計算器で検算しながら評価関数を直すんだ。
```

## A.4 章末まとめの書き方

### フォーマット

```markdown
## 章末まとめ

**霊夢**: この章、まとめると？

**魔理沙**: こうだぜ。

> **第N章まとめ**
>
> - ポイント1（動詞で終わる）
> - ポイント2
> - 次章: 第N+1章「タイトル」への接続
```

### 良い bullet の例

- ✅ 「スコア計算を先に実装する」
- ✅ 「合法解 → 改善の順で進める」
- ❌ 「焼きなましについて学んだ」（抽象的すぎ）

### 章の種類別のまとめの焦点

| 章の種類 | まとめに入れること |
|---------|-------------------|
| 概論・環境 | 手順・ツール・提出の型 |
| 技法 | いつ使うか・パラメータ・落とし穴 |
| ハンズオン章 | 実行コマンド・確認した出力 |
| 戦略・復習 | チェックリスト・次のアクション |
