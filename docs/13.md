# 第13章 タブーサーチと反復局所探索

> **到達目標（水色帯 1200〜1599）**: タブーリストで巡回を避け、反復局所探索（ILS）の骨格で TSP 的な解を改善できる。

---

## 13.1 タブーリストと多様性の確保

**霊夢**: 山登りや SA は、同じ手を何度も試しちゃうの？

**魔理沙**: 山登りは局所最適で止まる。タブーサーチは **毎回「いちばん良い手」を、悪化する手でも採用** して局所最適から歩き出す。ただしそれだけだと、悪化した次の手ですぐ元に戻ってしまう——だから **最近の手を一時禁止（タブー）** して、同じ所をぐるぐる回らないようにする。

| 用語 | 意味 |
|------|------|
| **タブー** | 禁止リストに載った移動 |
| **テニュア（tenure）** | 何ステップ禁止するか |
| **aspiration** | タブーでも「過去最良を更新」なら許可 |

**霊夢**: aspiration って、第13章のコードにある？

**魔理沙**: ある。`tabu_tsp.py` では **タブーでも過去最良（`best_len`）を更新する手なら採用** する。

```python
# python/ch13/tabu_tsp.py
new_len = cur_len - before + after  # 差分で新しい長さ（悪化もありうる）
# 付け足す辺 (a,c), (b,d) のどちらかがタブーなら、この手はタブー
is_tabu = tabu_until.get(edge_key(a, c), -1) >= it or tabu_until.get(edge_key(b, d), -1) >= it
if is_tabu and new_len >= best_len - 1e-9:
    continue  # タブーかつ最良更新にならない → スキップ（aspiration 不成立）
if best_move is None or new_len < best_move[0]:
    best_move = (new_len, i, k)
```

```go
// go/ch13/tabu_tsp.go — 同じ判定
tabu := isTabu(edgeKey(a, c), it) || isTabu(edgeKey(b, d), it)
if tabu && newLen >= bestLen-1e-9 {
	continue // タブーかつ最良更新にならない
}
```

**霊夢**: 何をタブーにしてるの？ 「(i, k) の手」そのもの？

**魔理沙**: **辺** だ。2-opt は辺 (a,b) と (c,d) を外して (a,c) と (b,d) を付ける。外した辺を `tabu_tenure` 反復のあいだ **付け直し禁止** にする。「位置の組 (i, k)」をタブーにすると、反転で並びが変わったあとは別の意味になってしまうので、**解の中身（辺）** で覚えるのが定番だ。

```python
# python/ch13/tabu_tsp.py — 外した辺 (a,b), (c,d) をしばらく付け直さない
tabu_until[edge_key(a, b)] = it + tabu_tenure
tabu_until[edge_key(c, d)] = it + tabu_tenure
```

**魔理沙**: 「いつまで禁止か」を辞書に持てば、期限切れの判定は `tabu_until[e] >= it` の比較だけで済む。

## 13.2 反復局所探索（ILS）の構成

**霊夢**: ILS って、山登りを何度もやり直す感じ？

**魔理沙**: **Iterated Local Search** は次の3点セットだ。

```
  初期解
    ↓
┌───────────────────┐
│ 局所探索（2-opt等）│←──┐
└─────────┬─────────┘   │
          ↓               │
      局所最適            │
          ↓               │
┌───────────────────┐   │
│  摂動（キック）    │───┘
└───────────────────┘
```

| 段 | 本リポジトリ |
|----|-------------|
| 初期解 | ランダムシャッフル（seed=42） |
| 局所探索 | 2-opt 近傍のタブーサーチ（悪化も受理・辺をタブー） |
| 摂動 | （演習で追加）ランダムスワップ |

**霊夢**: 今の `tabu_tsp` は ILS までやってない？

**魔理沙**: その通り。**タブーサーチ 1 本** だ。ILS にするには `max_iter` 後に **キック** して `cur` を乱し、外側ループで繰り返す（演習2）。

## 13.3 摂動（Perturbation）の設計

**霊夢**: 摂動って、解をわざと壊すの？

**魔理沙**: **局所最適から離れる** ための操作だ。強すぎると品質が落ち、弱すぎると抜け出せない。

| 摂動 | 向き | 注意 |
|------|------|------|
| ランダム 2-opt | TSP 向き | 短い逆転 |
| セグメント再配置 | VRP 向き | 容量制約を壊さない |
| 複数都市スワップ | 強い | あとで長めに局所探索 |

**霊夢**: 第6章の 2-opt と何が違うの？

**魔理沙**: 近傍の形は同じ。違いは3つ——**悪化する手でも最良なら採用** する点、**タブーで「直前に戻す手」** を避ける点、**aspiration で最良更新** は逃さない点だ。差分更新で `new_len = cur_len - before + after` としているのは第6章と同じ思想だ。

```python
# python/ch13/tabu_tsp.py
def apply_reverse(tour: List[int], i: int, k: int) -> None:
    tour[i + 1 : k + 1] = reversed(tour[i + 1 : k + 1])
```

```go
// go/ch13/tabu_tsp.go
func reverseSegment(tour []int, lo, hi int) {
    for lo < hi {
        tour[lo], tour[hi] = tour[hi], tour[lo]
        lo++
        hi--
    }
}
```

### パラメータ早見表

| パラメータ | 本リポジトリ | 上げると | 下げると |
|-----------|-------------|---------|---------|
| `tabu_tenure` | 12 | 戻りにくくなり遠くまで探す（良い手まで禁止しやすい） | すぐ元の解に戻り、同じ所を回りやすい |
| `max_iter` | 800 | 改善余地↑・時間↑ | 早く止まる |
| seed | 42 | 再現性あり | 変えると初期経路が変わる |

**霊夢**: 悪化も受け入れるなら、いつ止まるの？

**魔理沙**: 基本は **`max_iter` 回**（本番なら残り時間）で打ち切る。途中で止まるのは、すべての手がタブーで `best_move is None` になったときだけだ。返すのは現在解ではなく **歴代最良 `best`**。

## 13.4 ハンズオン: 経路問題にタブーサーチを適用する

**霊夢**: データは第6章と同じ形式？

**魔理沙**: 先頭が `n`、続けて `n` 点の座標。`data/ch13/sample.txt` は 8 都市だ。

```bash
python python/ch13/tabu_tsp.py < data/ch13/sample.txt
go run go/ch13/tabu_tsp.go < data/ch13/sample.txt
```

検証済み出力の例:

```text
n=8 before=48.49 after=28.98 tabu_tenure=12
```

（Go 版は乱数列が Python と違うので初期巡回と `before` は変わる（例: `before=59.49`）。到達する `after=28.98` は同じ。）

**霊夢**: 48 から 29 まで下がってる。山登り（第6章）と比べるとどう？

**魔理沙**: 8 点だとどちらも最適 28.98 に届くので差が出ない。ランダムな 30 点で同じ初期解から比べると、手元では 3 ケースとも タブー の方が短かった（例: 2-opt 山登り 460.61 → タブー 449.03）。山登りが止まる局所最適から、タブーは悪化を受け入れて歩き出せるからだ。

### ハンズオンの進め方

1. **読む** — `tabu_search` の二重ループ `(i, k)` が 2-opt 近傍
2. **写す** — 上記コマンドで `tour:` 行を確認
3. **改変** — `tabu_tenure=12` を `6` / `24` に振る
4. **コンテスト形式** — `max_iter=800` を残り時間で打ち切る（第11章タイマーと合成）

### コアループ（抜粋）

```python
# python/ch13/tabu_tsp.py
for it in range(max_iter):
    best_move = None
    for i in range(n):
        for k in range(i + 2, limit):
            # before / after で差分評価。改善しない手も候補に入れる
            ...
    if best_move is None:
        break  # 全部の手がタブー
    apply_reverse(cur, i, k)
    # ... 外した辺をタブーに登録
    if cur_len < best_len - 1e-9:
        best = cur[:]
```

```go
// go/ch13/tabu_tsp.go
tour, after := tabuSearch(pts, tour, 12, 800)
fmt.Printf("n=%d before=%.2f after=%.2f tabu_tenure=12\n", len(pts), before, after)
```

### SA・山登りとの位置づけ

| 手法 | 悪化の受理 | 記憶 | 向く場面 |
|------|-----------|------|---------|
| 山登り | しない | なし | 速い仕上げ |
| SA | 確率的 | なし（温度のみ） | 広い谷 |
| タブー | 最良の非タブー手なら悪化も受理 | 最近外した辺 | 巡回・置換 |

**霊夢**: 第11章パイプラインにタブーを挟むなら？

**魔理沙**: `greedy → tabu → SA` のように **タブーで整数っぽく詰めてから SA** もあり得る。時間の `%` を stderr に出せ（第11章）。

```python
# python/ch13/tabu_tsp.py — 初期化（main より）
rng = random.Random(42)
tour = list(range(len(pts)))
rng.shuffle(tour)
before = tour_length(pts, tour)
tour, after = tabu_search(pts, tour)  # 既定: tabu_tenure=12, max_iter=800
```

## 章末まとめ

**霊夢**: タブーは悪化してでも動き続けて、戻る手は禁止、最良更新だけは例外——なのね。

**魔理沙**: ILS はその上に **摂動で再起動** を載せる。まとめだ。

> **第13章まとめ**
>
> - **最良の非タブー手を悪化でも採用** し、局所最適から歩き出す
> - **タブー**: 最近外した辺を一定反復のあいだ付け直さない（戻りを防ぐ）
> - **aspiration**: タブーでも過去最良を更新する手は許可
> - **ILS** = 局所探索 + 摂動 +（外側ループ）
> - 実装: `python/ch13/tabu_tsp.py` / `go/ch13/tabu_tsp.go` / `data/ch13/sample.txt`
> - 検証例: `before=48.49` → `after=28.98`（`tabu_tenure=12`）
> - 次章: Union-Find / Fenwick で合法操作生成を高速化（第14章）

**霊夢**: 第6章の 2-opt にタブーと aspiration が載った感じね。

**魔理沙**: 水色帯では **メタ手法の組み合わせ** が本題だ。次はデータ構造で **同じ近傍を何倍も速く** 試せるようにするんだぜ。
