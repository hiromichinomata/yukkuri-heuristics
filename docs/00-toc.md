# ゆっくり霊夢・魔理沙が教えるヒューリスティック競技プログラミング

> **ゆっくり霊夢** と **ゆっくり魔理沙** の掛け合いで、AtCoder Heuristic Contest（AHC）のレーティング帯ごとに必要な知識を学ぶ。
> 各章は **掛け合い解説 → ハンズオン → Python 実装 → Go 実装 → 演習** の流れで構成する。

## 登場人物

| キャラクター | 役割 |
|-------------|------|
| ゆっくり霊夢 | 初心者視点。素朴な疑問・勘違い・つまずきを代弁する |
| ゆっくり魔理沙 | 解説役。概念の説明、コード例の提示、霊夢の疑問に答える |

## 各章の構成

1. **掛け合い解説** — 霊夢と魔理沙の台本形式で概念を説明する
2. **ハンズオン** — 解説で触れた内容を手を動かして試す
3. **Python / Go 実装** — 両言語で同じ解法を提示する
4. **演習** — 読者が自分で改変・応用する課題
