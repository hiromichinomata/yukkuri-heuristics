## 2.1 AtCoder アカウント登録と AHC 参加方法

**霊夢**: いよいよ環境の話ね。何から始めればいいの？

**魔理沙**: まず [AtCoder](https://atcoder.jp/) にアカウントを作る。Algo 部門で既に登録済みなら、そのまま使えるぜ。

**霊夢**: AHC だけ別登録？

**魔理沙**: 不要だ。**同じアカウント**で Heuristic コンテストにも参加する。コンテスト一覧で **「H」** マークのものがヒューリスティック系だ。

| ステップ | やること |
|---------|---------|
| 1 | [AtCoder 新規登録](https://atcoder.jp/register)（未登録の場合） |
| 2 | コンテスト一覧で AHC / Intro HC を探す |
| 3 | 開催前に「参加登録」 |
| 4 | 開始後、問題ページから提出 |

**霊夢**: Rated と Unrated って何？

**魔理沙**: **Rated** は Heuristic レートが更新される参加。**Unrated** は練習扱いでレートは動かない。初めてなら Unrated でもいいが、本番は Rated を選ぶのがおすすめだ。

**霊夢**: Heuristic レートは下がらないって第1章で習ったわ。

**魔理沙**: 覚えてるな。Rated でも**提出しないとレート計算対象外**だ。Intro HC みたいに複数問題ある場合も、**1回以上提出**が必要な形式が多い。

**霊夢**: 提出の流れは？

**魔理沙**: だいたいこうだ。

```
1. 問題ページを開く
2. 言語を選ぶ（Python / Go など）
3. ソースを貼る or ファイルアップロード
4. 提出 → ジャッジ待ち → スコア表示
5. 5分空けて再提出（同一問題）
```

```text
# AtCoder 提出画面で確認すること
- 言語: Python (PyPy3) / Go など
- ソース: main 相当がエントリポイント
- 実行時間制限 (TL): 問題ごとに 2〜3 秒など
- メモリ制限: 1024 MiB など
```

**霊夢**: 本番提出の前にローカルで試したいの。

**魔理沙**: それがこの章のメインテーマだ。2.4 と 2.5 で**ローカルテスター**を回すぜ。

```python
# python/ch02/ahc_main.py — AHC 提出用の最小 main テンプレート
import sys
import time


class Timer:
    def __init__(self, limit_sec: float):
        self.start = time.perf_counter()
        self.limit = limit_sec

    def expired(self) -> bool:
        return time.perf_counter() - self.start >= self.limit


def solve():
    # TODO: 解法本体
    pass


def main():
    timer = Timer(2.0)  # TL 2 秒想定
    while not timer.expired():
        solve()
        break  # 探索ループに差し替え


if __name__ == "__main__":
    main()
```

> **注**: リポジトリ内スクリプトは `python python/ch02/foo.py` で実行する。AtCoder 提出時は**1ファイルにまとめる**か、ローカルで結合してから貼る。

**霊夢**: PyPy3 は使った方がいいの？

**魔理沙**: ループが重い解法なら PyPy3 が速いことが多い。ただし**ローカルが CPython** でも、提出だけ PyPy3 という使い方はよくある。最終的には本番 TL で計測して選べ。

| 用途 | おすすめ |
|------|---------|
| 学習・デバッグ | CPython + venv |
| 本番（ループ多め） | PyPy3 |
| 本番（シンプルな処理） | CPython でも可 |

### 高速 I/O テンプレート

AHC では stdin が大きいことがある。`bufio` を使う。

```go
// go/templates/io_template.go — bufio 読み込み（抜粋）
package main

import (
    "bufio"
    "fmt"
    "os"
    "strconv"
    "strings"
)

func readInts(sc *bufio.Scanner) []int {
    sc.Scan()
    parts := strings.Fields(sc.Text())
    out := make([]int, len(parts))
    for i, p := range parts {
        v, _ := strconv.Atoi(p)
        out[i] = v
    }
    return out
}

func main() {
    sc := bufio.NewScanner(os.Stdin)
    n := readInts(sc)[0]
    fmt.Println(n)
}
```

## 2.4 ローカルテスター・ビジュアライザの使い方

**霊夢**: ローカルテスターって何？

**魔理沙**: 本番ジャッジなしで**手元で点数を測る**仕組みだ。AHC 公式はだいたい次の3つを配る。

| ツール | 役割 | 典型コマンド |
|--------|------|-------------|
| gen | 入力生成 | `gen 0 > input.txt` |
| score | スコア計算 | `score input.txt output.txt` |
| vis | ビジュアライズ | `vis input.txt output.txt` |

Intro HC も同形式: [tools (Rust)](https://img.atcoder.jp/intro-heuristics/tools.zip) / [Windows ビルド済み](https://img.atcoder.jp/intro-heuristics/tools_windows.zip)

**霊夢**: Rust 必須なの？ 嫌なのだ……

**魔理沙**: 公式 tools は Rust 製だが、**Rust がなくても開発できる**。方法は2つ。

1. **Windows 用ビルド済みバイナリ**を使う
2. **スコア計算を Python / Go で自作**する（第1章の `score_intro_hc`）

本書では 2 を基本に、公式 tools は「あると便利」として紹介する。

### 公式 tools の流れ（Rust 環境あり）

```bash
# Intro HC tools を展開したディレクトリで
cargo build --release

# シード 0 の入力を生成
cargo run --release --bin gen -- 0 > input.txt

# 解法を実行
python python/ch02/sample_solver.py < input.txt > output.txt

# スコア計算
cargo run --release --bin score -- input.txt output.txt

# ビジュアライザ（HTML 出力など）
cargo run --release --bin vis -- input.txt output.txt
```

### 本リポジトリのローカル評価

Rust がなくても、**ソルバ + 自作スコア計算**で同じパイプラインを再現できる。

```text
input.txt  ──→  sample_solver  ──→  output.txt
                                      │
input.txt + output.txt ──→  score_intro_hc  ──→  各日満足度 + 最終スコア
```

```bash
# 一括実行
./tools/local_test.sh data/ch01/sample.txt

# 環境チェック
./tools/check_env.sh
```

```python
# python/ch02/run_local.py — パイプラインを Python だけで実行
import subprocess
import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parents[2]

def run(input_path, solver, scorer):
    inp = input_path.read_text()
    sol = subprocess.run(
        [sys.executable, str(solver)],
        input=inp, text=True, capture_output=True, check=True,
    )
    combined = inp + sol.stdout
    score = subprocess.run(
        [sys.executable, str(scorer)],
        input=combined, text=True, capture_output=True, check=True,
    )
    print(score.stdout.strip())
    print("final:", score.stderr.strip())

if __name__ == "__main__":
    run(
        ROOT / "data" / "ch02" / "input_only.txt",
        ROOT / "python" / "ch02" / "sample_solver.py",
        ROOT / "python" / "ch01" / "score_intro_hc.py",
    )
```
