## 0.2 ゆっくり解説の読み方

**霊夢**: この本、普通の解説本と何が違うの？

**魔理沙**: 霊夢と俺が**掛け合い**で説明する形式だ。霊夢が素朴な疑問を投げて、俺が答える流れだぜ。

**霊夢**: つまり私が「読者の代わり」なのね。

**魔理沙**: その通り。1つの節はだいたい次の流れだ。

```
1. 霊夢が「〜って何？」と聞く
2. 魔理沙が概念を説明する
3. 霊夢が勘違い or 突っ込みを入れる
4. 魔理沙がコードで示す
5. 二人で章末まとめ
```

**霊夢**: 例を見せて。

**魔理沙**: いいぜ。第5章「貪欲法」のイメージだ。

**霊夢**: 貪欲法って、欲張りに選ぶやつでしょ？

**魔理沙**: だいたい合ってる。毎回「今いちばん良さそうな選択」をする方法だぜ。

```python
# Python: 毎回スコアが最大になる操作を選ぶ（超シンプル版）
def greedy(items):
    items.sort(key=lambda x: x.score, reverse=True)
    selected = []
    for item in items:
        if item.fits(selected):
            selected.append(item)
    return selected
```

```go
// Go: 同じ考え方
func greedy(items []Item) []Item {
    sort.Slice(items, func(i, j int) bool {
        return items[i].Score > items[j].Score
    })
    selected := []Item{}
    for _, item := range items {
        if item.Fits(selected) {
            selected = append(selected, item)
        }
    }
    return selected
}
```

**霊夢**: へえ、Python と Go で並べてあるの。

**魔理沙**: そうだ。読み慣れた方から入って、もう一方は**対応表を見ながら**読めばいい。両方書けるようになる必要はない。コンテストで使う1言語を決めて、もう一方は「こう書くんだな」と参考にする程度で十分だぜ。

**霊夢**: 章末まとめってどんな感じ？

**魔理沙**: こんな感じだ。

> **章末まとめ（例）**
>
> - 貪欲法 = 毎回ベストな選択を繰り返す
> - 常に最適解にはならない（局所最適にハマる）
> - ヒューリスティックでは「まず貪欲で形を作る」ことが多い

**霊夢**: わかった。質問 → 解説 → コード → まとめ、ね。

## 0.4 ハンズオンの進め方

**霊夢**: 「ハンズオン」って、手を動かす练习のこと？

**魔理沙**: そうだ。各章の流れは **読む → 写す → 改変する → コンテスト形式で解く** の4段階だぜ。

**魔理沙**: 最初はそれでいい。ただし「なんとなくわかった」で終わらせない。次の Step で必ず写すんだ。

### Step 2: 写す

**魔理沙**: だから **写経より clone + 実行** を推奨する。写経は理解が深まったあと、記憶定着用にやればいい。

**霊夢**: いきなり全部書き換えるんじゃないんだ。

**魔理沙**: そう。**1パラメータずつ** 触る。ヒューリスティックはパラメータの影響が大きいから、ログを取りながら変える癖をつけろ。

```python

```


### Step 4: コンテスト形式で解く

AHC 形式に近づけて解く。

| 項目 | AHC の実際 | ハンズオンでの再現 |
|------|-----------|-------------------|
| 制限時間 | 問題ごとに2〜3秒など | 同じ TL で計測 |
| 提出間隔 | 5分 | ローカルでは不要。スコア改善を記録 |
| スコア | 高いほど良い | 自作スコア関数 or 公式テスター |

```python
# python/templates/timer.py
import time

class Timer:
    def __init__(self, limit_sec: float):
        self.start = time.perf_counter()
        self.limit = limit_sec

    def elapsed(self) -> float:
        return time.perf_counter() - self.start

    def remaining(self) -> float:
        return self.limit - self.elapsed()

    def expired(self) -> bool:
        return self.remaining() <= 0
```

```go
// go/templates/timer.go
package main

import "time"

type Timer struct {
    start time.Time
    limit time.Duration
}

func NewTimer(limitSec float64) *Timer {
    return &Timer{
        start: time.Now(),
        limit: time.Duration(limitSec * float64(time.Second)),
    }
}

func (t *Timer) Remaining() time.Duration {
    return t.limit - time.Since(t.start)
}

func (t *Timer) Expired() bool {
    return t.Remaining() <= 0
}
```

**霊夢**: 時間切れになったらどうするの？

**魔理沙**: **今持ってる最良解を出力** する。AHC でもそうだ。最後まで探索し続けて何も出さない、が一番もったいないんだぜ。

## 0.5 Python / Go のコード対応表

**霊夢**: 両方書ける人って少ないと思うの。対応表があると助かるわ。

### 入出力

| やりたいこと | Python | Go |
|-------------|--------|-----|
| 標準入力1行 | `input()` | `bufio.NewScanner(os.Stdin)` |
| 整数列 | `map(int, input().split())` | `fmt.Scan` / 自前 split |
| 出力 | `print(x)` | `fmt.Println(x)` |
| 高速出力 | `sys.stdout.write` | `bufio.NewWriter` |

```python
    return list(map(int, sys.stdin.readline().split()))

def main():
    n, = read_ints()
    a = read_ints()
    print(sum(a))

if __name__ == "__main__":
    main()
```

```go
// go/templates/io_template.go
package main

import (
    "bufio"
    "fmt"
    "os"

func readInts(sc *bufio.Scanner) []int {
    sc.Scan()
```

### データ構造

| やりたいこと | Python | Go |
|-------------|--------|-----|
| 動的配列 | `list` | `[]T` / `append` |
| 辞書 | `dict` | `map[K]V` |
| 集合 | `set` | `map[T]struct{}` |
| 優先度付きキュー | `heapq` | `container/heap` |
| 座標 (y, x) | `(y, x)` タプル | 構造体 or `[2]int` |

```python
# python/templates/heap_example.py
import heapq

pq = []
heapq.heappush(pq, (10, "a"))
heapq.heappush(pq, (5, "b"))
best = heapq.heappop(pq)  # (5, 'b')
```

```go
// go/templates/heap_example.go
package main

import (
    "container/heap"
)

type Item struct {
    Score int
    ID    string
}
type PriorityQueue []Item

func (pq PriorityQueue) Len() int            { return len(pq) }
func (pq PriorityQueue) Less(i, j int) bool  { return pq[i].Score < pq[j].Score }
func (pq PriorityQueue) Swap(i, j int)        { pq[i], pq[j] = pq[j], pq[i] }
func (pq *PriorityQueue) Push(x any)         { *pq = append(*pq, x.(Item)) }
func (pq *PriorityQueue) Pop() any {
    old := *pq
    n := len(old)
    item := old[n-1]
    *pq = old[:n-1]
    return item
}
```

### 定番テンプレート（焼きなまし法）

**霊夢**: ヒューリスティックでよく出るやつ、早めに見たいの。

**魔理沙**: 焼きなまし法（SA）の骨格だ。詳しくは第8章で扱うが、形だけ先に見ておけ。

```python
# python/templates/sa_template.py
import math
import random

def sa(initial_score, neighbor_fn, score_fn, time_limit_sec=2.0):
    """neighbor_fn(state) -> new_state or None
       score_fn(state) -> int (high is better)
    """
    import time
    start = time.perf_counter()

    state = initial_state = ...
    best_state = state
    best_score = score = score_fn(state)

    T = 100.0
    ALPHA = 0.995

    while time.perf_counter() - start < time_limit_sec:
        new_state = neighbor_fn(state)
        if new_state is None:
            continue
        new_score = score_fn(new_state)
        delta = new_score - score

        if delta >= 0 or random.random() < math.exp(delta / T):
            state = new_state
            score = new_score
            if score > best_score:
                best_score = score
                best_state = state

        T *= ALPHA

    return best_state, best_score
```

```go
// go/templates/sa_template.go
package main

import (
    "math"
    "math/rand"
    "time"
)

func sa(
    neighbor func(state any) (any, bool),
    score func(state any) int,
    limit time.Duration,
) (bestState any, bestScore int) {
    start := time.Now()
    state := initialState()
    bestState = state
    bestScore = score(state)
    curScore := bestScore

    T := 100.0
    const alpha = 0.995
    rng := rand.New(rand.NewSource(42))

    for time.Since(start) < limit {
        newState, ok := neighbor(state)
        if !ok {
            continue
        }
        newScore := score(newState)
        delta := float64(newScore - curScore)

        if delta >= 0 || rng.Float64() < math.Exp(delta/T) {
            state = newState
            curScore = newScore
            if curScore > bestScore {
                bestScore = curScore
                bestState = state
            }
        }
        T *= alpha
    }
    return bestState, bestScore
}

func initialState() any { return nil }
```

**霊夢**: `...` の部分は問題ごとに埋めるのね。

**魔理沙**: そう。**テンプレートは共通、問題固有部分だけ差し替える** のがヒューリスティック実装の基本だぜ。
