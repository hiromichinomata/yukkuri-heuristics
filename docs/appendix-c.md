## C.2 経路・巡回（path）

| 項目 | 内容 |
|------|------|
| キーワード | TSP, 巡回, 訪問順, 距離 |
| 状態 | 頂点の訪問順序 |
| Move | 2-opt, swap, LNS 破壊区間 |
| 例題 | [AHC005](https://atcoder.jp/contests/ahc005), AHC002 |
| 本書 | 第5章（貪欲配達）、第6章（2-opt）、第24章（LNS） |

**最初に確認すること**

1. 距離: ユークリッド / マンハッタン / 重み付きグラフ
2. 固定始点・終点の有無
3. 対称性（逆向き OK か）

```python
# 2-opt: 区間 [i+1, j] を反転
def two_opt(tour, i, j):
    return tour[: i + 1] + tour[i + 1 : j + 1][::-1] + tour[j + 1 :]
```

## C.3 スケジューリング（scheduling）

| 項目 | 内容 |
|------|------|
| キーワード | 日程, decay, 満足度, 割当 |
| 状態 | 時間軸上の割当（種類・順序） |
| Move | 1日変更、swap 2日、種類変更 |
| 例題 | [Intro HC](https://atcoder.jp/contests/intro-heuristics), AHC011 |
| 本書 | 第1章、第3章、第8章、第10章 |

**最初に確認すること**

1. スコアは日次か累積か
2. 過去の割当が未来のコストに効くか（Intro HC の decay）
3. 貪欲1パスでどこまで行くか

## C.4 グリッド操作・パズル（puzzle）

| 項目 | 内容 |
|------|------|
| キーワード | スライド, 連結, 操作列, 合法手 |
| 状態 | 盤面 + 空白位置 |
| Move | 上下左右、ピース移動 |
| 例題 | AHC010, AHC014 |
| 本書 | 第4章（シミュレーション）、第9章、第14章 |

**最初に確認すること**

1. 状態空間のサイズ（ビーム幅の上限）
2. 評価関数: マンハッタン距離、連結成分数 など
3. ビジュアライザ必須か

# ヒューリスティック例: 各タイルの目標マンハッタン和

    return sum(manhattan(state.pos[t], goal.pos[t]) for t in tiles)

## パターン判定フロー

```text
問題文を読む
  ├─ クエリ形式？ → interactive
  ├─ 複数キャラの行動？ → multi_agent
  ├─ 訪問順・経路？ → path
  ├─ 日程・割当・時間軸？ → scheduling
  ├─ 盤面操作・パズル？ → puzzle
  └─ 位置・矩形・配置？ → placement
```
