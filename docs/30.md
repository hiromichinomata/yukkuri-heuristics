## 30.1 解説スライド・editorial の読み方

**霊夢**: コンテスト後の解説、どう読めばいいの？

**魔理沙**: **結果の確認** と **手法の抽出** を分ける。

| 段階 | やること |
|------|---------|
| 1. 自分の順位・スコア | どこまで届いたか |
| 2. 公式 editorial | 想定解法・データ生成 |
| 3. 上位スライド | パイプライン・パラメータ |
| 4. 差分メモ | 「自分に足りない1行」 |

読む順（おすすめ）:

```
公式概要 → 上位3本のスライド → 気になった近傍だけコード検索
```

**霊夢**: 全部理解しないとダメ？

**魔理沙**: **1アイデア持ち帰り** で十分。第30章ではそれを **チュートリアル骨子** に落とす。

AtCoder 関連:

- [Heuristic Contest 概要](https://info.atcoder.jp/overview/contest/heuristic)
- [Introduction to Heuristics Contest](https://atcoder.jp/contests/intro-heuristics)（AHC001 等）

## 30.2 コミュニティ（X, Discord, ブログ）から学ぶ

**霊夢**: 一人で復習するより、どこかで話した方がいい？

**魔理沙**: **公開メモ** は最強の復習だ。

| 場 | 向く内容 |
|----|---------|
| **X** | 当日の所感・スコア・1枚図 |
| **Discord** | 実装詳細・バグ共有 |
| **ブログ** | 週次振り返り・テンプレ更新 |
| **Qiita** | 灰色〜茶色向けの手順付き解説 |

**ルール**:

- 問題の **完全入力生成器** は載せない（ルール遵守）
- **自分のスコアと方針** は積極的に載せる
- 他人の解法は **credit** を明記

**霊夢**: 赤色帯の人が茶色向けに書くの？

**魔理沙**: 第30章ハンズオンのテーマだ。**教える前提** で書くと、抜けが見える。

## 30.3 自分の解法テンプレート集の作り方

**霊夢**: 付録Bみたいなテンプレ、自分でも作る？

**魔理沙**: **Contest 後** に更新するのが定石。

推奨構成:

```text
templates/
  io.py / io.go           … 入出力（付録B.1）
  timer.py                … 残り時間（B.5）
  sa.py                   … 焼きなまし（B.3）
  beam.py                 … ビーム（B.4）
  score/                  … 問題別スコア関数
  pipelines.md            … construct → improve の組合せ表
```

各テンプレに **メタデータ** を付ける:

```yaml
# meta: sa_template
used_in: [AHC008, AHC014]
last_updated: 2026-05-20
notes: "冷却 schedule を 0.995 に変更"
```

**霊夢**: 本書の `python/templates/` を fork すればいい？

**魔理沙**: そうだ。第0章・付録B を **自分用 repo** にコピーし、**勝った設定だけ** 残す。使わないテンプレは削除してスリムに。

## 30.4 次世代への解説 — 教えることで理解を深める

**霊夢**: 解説を書くと、何が得られるの？

**魔理沙**: 3つ。

1. **言い換え** — 問題を霊夢に説明できるレベルになる
2. **取捨選択** — 茶色向けに削ると、自分の核心が見える
3. **再利用** — 次の AHC の初期解設計にそのまま使える

ゆっくり解説の型（付録A）:

```markdown
**霊夢**: （〜って何？）
**魔理沙**: （定義 → 直感 → 具体例 → コード）
```

**霊夢**: 長文じゃなくていい？

**魔理沙**: **骨子 + 実行可能コマンド** があれば十分。第30章は `tutorial_outline.py` で骨子を **自動生成** する。

## 30.5 ハンズオン: 灰色〜茶色向けに、自分が解いた AHC 問題の解説を 1 本書く

**霊夢**: 何から書き始める？

**魔理沙**: `data/ch30/ahc001_outline.json` に **メタ情報** を入れ、骨子を出す。

### Step 1: メタ JSON を編集

```json
{
  "problem_id": "AHC001",
  "title": "企業の宣伝会場",
  "rating_band": "灰色〜茶色",
  "solved_score": 485000,
  "solver_style": "greedy_grow",
  "key_ideas": [
    "各企業の中心から矩形を拡大する貪欲",
    "重なり禁止をシミュレーションで確認"
  ],
  "sections": [
    "問題の言い換え（霊夢向け）",
    "入力と制約",
    "スコアの直感",
    "貪欲拡大の流れ",
    "改善の余地（焼きなまし・交換）"
  ]
}
```

### Step 2: 骨子を生成

```bash
python python/ch30/tutorial_outline.py
python python/ch30/tutorial_outline.py data/ch30/ahc001_outline.json > docs/my_ahc001_tutorial.md
```

生成ロジック（Python）:

```python
# python/ch30/tutorial_outline.py
def generate_outline(meta: Dict[str, Any]) -> str:
    for i, sec in enumerate(meta.get("sections", []), start=1):
        section_blocks.append(
            f"### {i}. {sec}\n\n"
            f"**霊夢**: （ここに読者の疑問）\n\n"
            f"**魔理沙**: （{sec}の解説を書く）\n"
        )
    return f"# 【ゆっくり解説骨子】{meta['problem_id']} ..."
```

骨子 JSON の読み方（Go でも同型）:

```go
// 概念: encoding/json で ahc001_outline.json を struct に載せる
type OutlineMeta struct {
    ProblemID   string   `json:"problem_id"`
    Title       string   `json:"title"`
    KeyIdeas    []string `json:"key_ideas"`
    Sections    []string `json:"sections"`
}
```

stdout 例（冒頭）:

```markdown
# 【ゆっくり解説骨子】AHC001 企業の宣伝会場

> 対象: 灰色〜茶色 / 自分の到達スコア: 485000 / 方針: `greedy_grow`

**霊夢**: AHC001って、何をする問題なの？
**魔理沙**: 一言で言うと「企業の宣伝会場」だぜ。
```

### Step 3: セクションを埋める

各 `### N. セクション` の **霊夢の疑問** と **魔理沙の解説** を肉付けする。コードは本書 **第4章** を参照:

```bash
python python/ch04/ahc001_grow.py < data/ch04/sample.txt
```

### Step 4: 読者ハンズオン（4ステップ）

1. 読む — 問題文とスコア式
2. 写す — `ahc001_grow.py` を実行
3. 改変 — 拡大順を1つ変える
4. コンテスト形式 — タイマー付き best-so-far

**公開前チェック**:

- [ ] 灰色読者が **最初のAC** まで辿れる
- [ ] コマンドが repo 内で動く
- [ ] 改善案は「次の一歩」1つだけ

## 演習

1. 自分が解いた別問題（AHC005 等）用に `ahc001_outline.json` をコピーし、`problem_id` だけ差し替えた骨子を生成する。
2. 上位解説スライドから **1枚** 選び、`pitfalls` に「自分がハマった点」を追記する。
3. `templates/` に **自分専用 SA テンプレ** を1ファイル追加し、`meta` コメントを書く。
4. 生成した骨子を **800字の X スレッド** に圧縮する（問題言い換え + 方針 + リンク）。

```bash
python python/ch30/tutorial_outline.py data/ch30/ahc001_outline.json | head -60
python python/ch04/ahc001_grow.py < data/ch04/sample.txt 2>&1 | tail -5
```
