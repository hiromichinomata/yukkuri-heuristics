# No Submit 回避チェックリスト（第21章）

コンテスト終了前に必ず確認する。

## 提出前（必須）

- [ ] **最低 1 回は提出した**（Rated 対象外になるのを防ぐ）
- [ ] 提出ファイルが **公式形式**（入出力・ビルド）に合っている
- [ ] ローカル `tools` / `score` で **サンプル入力が通る**
- [ ] 最終提出が **自分が意図したバージョン**（ログ・コミット時刻を確認）

## 時間配分

- [ ] 最初の 30 分で **問題理解と仮説メモ** を終えた
- [ ] 実装フェーズで **動く 0 点超え** を一度出した
- [ ] 改善フェーズで **計測付き** で 1 つだけ変更した
- [ ] 終了 **10 分前** にバッファを取った（提出・ビルド失敗用）

## ログ・振り返り

- [ ] 提出ごとに **スコアと時刻** を記録した（`mock_contest` / `contest_log.sh`）
- [ ] 最後の提出理由（何を変えたか）を 1 行書いた
- [ ] 次回の改善点を **3 つ** メモした

## よくある失敗

- [ ] 「あとで直す」だけで提出ゼロのまま終了していない
- [ ] ビルドエラー・CE を本番初提出で知っていない
- [ ] インタラクティブで **flush / プロトコル** を確認した
- [ ] 長期戦で **中間提出** を忘れていない
